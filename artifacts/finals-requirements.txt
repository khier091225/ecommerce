P006: 1. Project Overview
P007: Create a simple e-commerce mobile application using the provided Flutter starter code. The application is already functional, so the main task is to understand the code and transform it into your group's own online store by changing the store identity, categories, products, images, colors, text, and visual presentation.
P008: The starter code already contains product search, category filtering, a responsive product grid, product details, Add to Cart, a cart counter, cart total calculation, and screen navigation. These features must continue to work after customization.
[TABLE]
Important: Do not submit the starter application unchanged. The final application must clearly represent your selected e-commerce concept.
[/TABLE]

P041: 9. Customize and Add Products
P042: Near the top of main.dart, locate demoProducts. Replace the sample products with your own. Each product needs a name, price, category, description, and image path.
[TABLE]
Product(
  name: 'Gaming Mouse',
  price: 1299,
  category: 'Mouse',
  description:
      'A lightweight gaming mouse with adjustable sensitivity and programmable buttons.',
  image: 'assets/images/gaming_mouse.jpg',
),
[/TABLE]
P043: To add another product, copy one complete Product(...) block, paste it below an existing product, and replace the values. GridView.builder automatically creates a product card for every product in the list.
P044: 10. Add Product Images
P045: 1.  Create an assets folder in the main Flutter project.
P046: 2.  Inside assets, create an images folder.
P047: 3.  Copy your product images into assets/images/.
P048: 4.  Use simple filenames such as gaming_mouse.jpg, red_shirt.jpg, or history_book.png.
P049: 5.  Make sure the image path in each Product exactly matches the actual filename.
[TABLE]
your_project
|-- assets
|   `-- images
|       |-- gaming_mouse.jpg
|       |-- keyboard.jpg
|       `-- headset.jpg
|-- lib
|   `-- main.dart
`-- pubspec.yaml
[/TABLE]
P050: 11. Register the Image Folder
P051: Open pubspec.yaml and register the images folder under flutter: using the correct indentation.
[TABLE]
flutter:
  uses-material-design: true

  assets:
    - assets/images/
[/TABLE]
P052: Save the file, then run:
[TABLE]
flutter pub get
[/TABLE]
[TABLE]
Image Error Check: If an image does not appear, verify the filename, extension, path, pubspec.yaml indentation, and whether flutter pub get was run.
[/TABLE]
